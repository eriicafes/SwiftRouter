# SwiftRouter Skills

Reusable AI agent skills for building with [SwiftRouter](https://github.com/eriicafes/SwiftRouter).

## Install

```sh
npx skills add eriicafes/swift-router
```

## Available Skills

| Skill | Description |
|---|---|
| [`swift-router`](./swift-router/SKILL.md) | Stack routers, tab routers, root route data, route state, and URL parsing for SwiftRouter |
